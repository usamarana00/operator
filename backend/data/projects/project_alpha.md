# Project Alpha — Acme Corp

## Overview
Build a customer-facing dashboard for Acme Corp's logistics team. The system
displays shipment tracking, inventory levels, and delivery estimates in real time.

## Tech Stack
- Frontend: React + TypeScript
- Backend: FastAPI + PostgreSQL
- Hosting: AWS EC2 + RDS
